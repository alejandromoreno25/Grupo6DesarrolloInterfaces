# ¿Qué es este Repositorio?
Este repositorio pertenece al grupo 6, para la asignatura de Desarrollo de Interfaces. Este repositorio, está conectado con un segundo proyecto a la par del proyecto de trabajo final para centrar sus tareas en
el desarrollo de Interfaces.

# ¿Cómo usar el repositorio?
En este repositorio encontrarás las memorias como: "memoriaSprintX.md", a su vez encontrareis 
el prototipo y las presentaciones de cada sprint junto una carpeta assets con imágenes o documentos de apoyo al proyecto

# Cooevaluación
La coevaluación está en la carpeta cooevaluación con un readme que recoge cada cooevaluación del grupo en cada sprint.
